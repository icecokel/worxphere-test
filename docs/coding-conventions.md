# 코딩 컨벤션

## 파일명

- 소스 코드 파일명은 케밥 케이스를 사용한다.
- 프레임워크나 도구가 요구하는 고정 파일명은 그대로 사용한다.

예: `candidate-card.tsx`, `stage-move-menu.tsx`

## 모듈 내보내기

- 배럴 구조를 사용하지 않는다.
- 재내보내기만을 위한 `index.ts` 또는 `index.tsx`를 만들지 않는다.
- 모듈을 사용할 때 실제 파일 경로에서 직접 import한다.

## 함수

- 익명 함수를 사용하지 않는다.
- 함수와 콜백은 역할을 드러내는 이름을 가진 함수 선언 또는 함수 표현식으로 작성한다.
- 인라인 익명 화살표 함수와 익명 `function` 표현식은 별도의 이름 있는 함수로 분리한다.
