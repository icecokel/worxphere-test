# Requirements First

Treat explicit requirements, acceptance criteria, and provided source materials as the source of truth.

- Implement only behavior they support.
- Do not add speculative features, abstractions, policies, or compatibility work.
- If ambiguity materially changes the result, ask; otherwise choose the smallest compatible interpretation and state the assumption.
